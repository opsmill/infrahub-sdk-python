# How to create and configure an Infrahub client

This guide shows you how to create and configure an Infrahub client using the Python SDK. You'll learn how to set up authentication, configure proxy settings, and customize client behavior for your infrastructure automation workflows.

The Infrahub client is your primary interface for querying data, creating objects, managing schemas, and working with branches in Infrahub.

## Prerequisites

- Python 3.9 or higher
- Infrahub SDK installed (`pip install infrahub-sdk` or `poetry add infrahub-sdk`)
- Access to an Infrahub instance (local or remote)
- Valid credentials (API token or username/password) if authentication is required

## Step 1: Create a basic client connection

Choose between asynchronous or synchronous client based on your application's needs.

### For asynchronous applications

Create an `InfrahubClient` for async/await workflows:

```python
from infrahub_sdk import InfrahubClient

# Connect to local Infrahub instance
client = InfrahubClient(address="http://localhost:8000")

# Connect to remote instance
client = InfrahubClient(address="https://sandbox.infrahub.app")
```

### For synchronous applications

Create an `InfrahubClientSync` for traditional synchronous code:

```python
from infrahub_sdk import InfrahubClientSync

# Connect to local Infrahub instance
client = InfrahubClientSync(address="http://localhost:8000")

# Connect to remote instance
client = InfrahubClientSync(address="https://sandbox.infrahub.app")
```

## Step 2: Configure authentication (optional)

If your Infrahub instance requires authentication, configure it using either API tokens or username/password credentials.

### Using API tokens

API tokens provide secure, long-lived authentication. Set them via environment variable or directly in code:

<Tabs groupId="async-sync">
  <TabItem value="Async" default>

  ```python
  from infrahub_sdk import Config, InfrahubClient
  client = InfrahubClient(config=Config(api_token="token"))
  client = InfrahubClient() # token is read from the INFRAHUB_API_TOKEN environment variable
  ```

  </TabItem>
  <TabItem value="Sync">

  ```python
  from infrahub_sdk import Config, InfrahubClientSync
  client = InfrahubClientSync(config=Config(api_token="token"))
  client = InfrahubClientSync() # token is read from the INFRAHUB_API_TOKEN environment variable
  ```

  </TabItem>
</Tabs>

### Using username/password (JWT tokens)

For interactive authentication, use username and password. The SDK automatically handles JWT token generation and refresh:

<Tabs groupId="async-sync">
  <TabItem value="Async" default>

  ```python
  from infrahub_sdk import Config, InfrahubClient
  client = InfrahubClient(config=Config(username="admin", password="infrahub"))
  client = InfrahubClient() # token is read from the INFRAHUB_USERNAME and INFRAHUB_PASSWORD environment variable
  ```

  </TabItem>
  <TabItem value="Sync">

  ```python
  from infrahub_sdk import Config, InfrahubClientSync
  client = InfrahubClientSync(config=Config(username="admin", password="infrahub"))
  client = InfrahubClientSync() # token is read from the INFRAHUB_USERNAME and INFRAHUB_PASSWORD environment variable
  ```

  </TabItem>
</Tabs>

## Step 3: Configure client options (optional)

Customize client behavior using a `Config` object to enable debugging, set timeouts, or modify other settings.

### Enable GraphQL query debugging

To troubleshoot or understand the queries being sent to Infrahub, enable query echoing:

<Tabs groupId="async-sync">
  <TabItem value="Async" default>

  ```python
  from infrahub_sdk import Config, InfrahubClient
  config = Config(echo_graphql_queries=True)
  client = InfrahubClient(config=config)
  ```

  </TabItem>
  <TabItem value="Sync">

  ```python
  from infrahub_sdk import Config, InfrahubClientSync
  config = Config(echo_graphql_queries=True)
  client = InfrahubClientSync(config=config)
  ```

  </TabItem>
</Tabs>

## Step 4: Configure proxy settings (optional)

If you're behind a corporate firewall or need to route traffic through a proxy, configure proxy settings for HTTP requests.

### Single proxy for all requests

Use `INFRAHUB_PROXY` environment variable or the `proxy` configuration parameter to set a single proxy for all HTTP and HTTPS requests:

<Tabs groupId="async-sync">
  <TabItem value="Async" default>

  ```python
  from infrahub_sdk import Config, InfrahubClient
  config = Config(proxy="http://proxy.example.com:8080")
  client = InfrahubClient(config=config)
  
  # Or using environment variable
  # export INFRAHUB_PROXY=http://proxy.example.com:8080
  client = InfrahubClient()
  ```

  </TabItem>
  <TabItem value="Sync">

  ```python
  from infrahub_sdk import Config, InfrahubClientSync
  config = Config(proxy="http://proxy.example.com:8080")
  client = InfrahubClientSync(config=config)
  
  # Or using environment variable
  # export INFRAHUB_PROXY=http://proxy.example.com:8080
  client = InfrahubClientSync()
  ```

  </TabItem>
</Tabs>

### Separate proxies for HTTP and HTTPS

Use `INFRAHUB_PROXY_MOUNTS_HTTP` and `INFRAHUB_PROXY_MOUNTS_HTTPS` environment variables to configure different proxies for HTTP and HTTPS requests:

```bash
export INFRAHUB_PROXY_MOUNTS_HTTP=http://http-proxy.example.com:8080
export INFRAHUB_PROXY_MOUNTS_HTTPS=http://https-proxy.example.com:8080
```

<Tabs groupId="async-sync">
  <TabItem value="Async" default>

  ```python
  from infrahub_sdk import InfrahubClient
  # Proxy configuration is read from environment variables
  client = InfrahubClient()
  ```

  </TabItem>
  <TabItem value="Sync">

  ```python
  from infrahub_sdk import InfrahubClientSync
  # Proxy configuration is read from environment variables
  client = InfrahubClientSync()
  ```

  </TabItem>
</Tabs>

:::warning
The `proxy` and `proxy_mounts` configurations are mutually exclusive. You cannot use both at the same time.
:::

## Step 5: Set the default branch (optional)

Configure your client to work with a specific Infrahub branch. This is useful for development workflows where you want to isolate changes.

<Tabs groupId="async-sync">
  <TabItem value="Async" default>

  ```python
  from infrahub_sdk import InfrahubClient, Config
  config = Config(default_branch="other-branch")
  client_other_branch = InfrahubClient(config=config)

  tag_other_branch = await client_other_branch.get(kind="BuiltinTag", name__value="RED")
  tag_main_branch = await client_other_branch.get(kind="BuiltinTag", name__value="RED", branch="main")
  ```

  </TabItem>
  <TabItem value="Sync">

  ```python
  from infrahub_sdk import InfrahubClientSync, Config
  config = Config(default_branch="other-branch")
  client_other_branch = InfrahubClientSync(config=config)

  tag_other_branch = client_other_branch.get(kind="BuiltinTag", name__value="RED")
  tag_main_branch = client_other_branch.get(kind="BuiltinTag", name__value="RED", branch="main")
  ```

  </TabItem>
</Tabs>

## Validation

To verify your client is properly configured and can connect to Infrahub, test the connection:

<Tabs groupId="async-sync">
  <TabItem value="Async" default>

  ```python
  from infrahub_sdk import InfrahubClient, Config
  
  # Test connection and authentication
  async def test_connection():
      client = InfrahubClient(address="http://localhost:8000")
      
      # Try to fetch schema to validate connection
      try:
          schema = await client.schema.get()
          print(f"Successfully connected to Infrahub! Schema version: {schema.version}")
      except Exception as e:
          print(f"Connection failed: {e}")
  
  # Run the test
  await test_connection()
  ```

  </TabItem>
  <TabItem value="Sync">

  ```python
  from infrahub_sdk import InfrahubClientSync, Config
  
  # Test connection and authentication
  def test_connection():
      client = InfrahubClientSync(address="http://localhost:8000")
      
      # Try to fetch schema to validate connection
      try:
          schema = client.schema.get()
          print(f"Successfully connected to Infrahub! Schema version: {schema.version}")
      except Exception as e:
          print(f"Connection failed: {e}")
  
  # Run the test
  test_connection()
  ```

  </TabItem>
</Tabs>
