Generators, transforms and checks run without an explicit branch now target the configured `default_branch` (`INFRAHUB_DEFAULT_BRANCH`, `main` by default) instead of the active branch of the local Git checkout. If you run `infrahubctl transform`, `generator` or `check` locally and relied on them following your Git branch, set `INFRAHUB_DEFAULT_BRANCH_FROM_GIT=true` or pass `--branch` explicitly.
