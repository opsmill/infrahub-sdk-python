Reading the variables of a string Jinja2 template is now cached per template text, through `Jinja2Template.get_variables()` and the new function `get_template_variables()` in `infrahub_sdk.template`. With the cache, `get_variables()` no longer raises for a filter that the template object does not provide, and raises `JinjaTemplateSyntaxError` instead of `jinja2.exceptions.TemplateAssertionError` for an unknown test such as `{{ name is not_a_test }}`.
