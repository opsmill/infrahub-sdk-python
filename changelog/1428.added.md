Added support in object files for referencing an existing peer by HFID together with its node kind, as a mapping with `hfid` and an optional `kind` key. When a relationship points at a generic, `kind` names the node kind the HFID belongs to, so the server looks the HFID up on that node rather than on the generic. Works for relationships of cardinality one and inside the list of a relationship of cardinality many.
