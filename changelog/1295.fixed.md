Fixed a requested branch being replaced by the local Git branch when `default_branch_from_git` is enabled. This affected `client.clone(branch=...)`, generators and transforms created with `branch=...`, and the `--branch` option of `infrahubctl`. Calls that did not pass a branch went to the Git branch, so a generator run with `--branch` could read from the requested branch and create or update nodes on the Git branch.
