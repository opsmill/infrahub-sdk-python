Raised the `graphql-core` requirement from `>=3.2.12` to `>=3.2.14`, so installing the SDK can no longer resolve a release with the four denial-of-service bugs that 3.2.14 fixes in the GraphQL validator and parser. `infrahubctl graphql generate-return-types` validates query files with the affected rules. With 3.2.14, a query whose shared fragments or overlapping fields would make validation run for a very long time now fails validation with "Validation aborted.". A query nested more than 200 levels deep is now rejected with a syntax error. Before, a query slightly deeper than 200 levels could still parse, and deeper queries raised a Python `RecursionError`.
