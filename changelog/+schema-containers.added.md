Add the `containers` property of a node or generic schema and the `container` property of an attribute or relationship to the schema models. `validate_schema` accepts both properties, `infrahubctl schema format` places `containers` after `uniqueness_constraints`, `container` before `order_weight`, and orders the keys of each container item, and `infrahub_sdk.schema.main` exports `ContainerSchemaRead` and `ContainerSchemaWrite`. A container item has a `collapsible` flag, true by default, next to `collapsed`. `ContainerSchemaRead` carries the read-only `inherited` flag, and `infrahubctl schema export` writes only the containers a node or generic declares itself, without the ones it inherits from a generic.
