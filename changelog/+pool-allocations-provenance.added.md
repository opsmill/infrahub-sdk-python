Resource pool nodes have `get_pool_allocations()`, which lists the resources a pool holds as `PoolAllocation` entries: the node ID, kind, branch, display label (the number itself for a number pool), identifier and provenance. The provenance is `PoolAllocationProvenance.ALLOCATED` when the number pool allocated the number, `PoolAllocationProvenance.PROVIDED` when a user attached it, and `None` for IP pools. It requires Infrahub 1.12 or later. `get_pool_allocated_resources()` is unchanged.
