`InfrahubSchema.export` and `InfrahubSchemaSync.export` now return the document that Infrahub builds, as a `SchemaExportDocument`, instead of a `SchemaExport`. They take a `mode` argument, `BRIEF` by default. `split_by_namespace` splits a `SchemaExportDocument` into one document per namespace. Against an Infrahub server without the schema export endpoint, they raise `VersionNotSupportedError` with the first Infrahub release that has it. When `namespaces` names a namespace that does not exist on the branch, or a namespace reserved for Infrahub such as `Core`, they raise the new `SchemaNamespaceNotFoundError`, with one message for each such namespace. When the document holds a value this SDK version cannot read, such as an attribute kind added in a later Infrahub release, they raise `InvalidResponseError`.
