`InfrahubSchema.export` and `InfrahubSchemaSync.export` now return the document that Infrahub builds, as a `SchemaExportDocument`, instead of a `SchemaExport`. They take a `mode` argument, `BRIEF` by default. `split_by_namespace` splits a `SchemaExportDocument` into one document per namespace. Against an Infrahub server without the schema export endpoint, they raise `VersionNotSupportedError` with the first Infrahub release that has it.
