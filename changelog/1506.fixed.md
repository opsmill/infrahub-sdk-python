The client store now keeps one entry per node and branch. Before, each query that returned a node already in the store, such as a repeated `client.get()`, `client.all()` or `client.filters()`, added another copy and kept the previous one in memory, so a long-running process that reused one client used more memory on every query. Lookups by ID, HFID or key return the copy from the latest query, as before, and `client.store.count()` now returns the number of distinct nodes. `node.delete()` now removes the node from the client store, and looking up a node on a branch the store does not hold no longer adds an empty entry for that branch.
