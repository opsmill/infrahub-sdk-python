`retry_on_failure` now also retries a request whose connection is dropped before any response arrives, which is the shape a load balancer failover or a server restart takes on a request that is already in flight. httpx reports that as a protocol error rather than a network error, so it used to escape the retry handler and abort the operation even with an unlimited retry budget. It is now reported as `ServerNotReachableError`, like any other lost connection.
