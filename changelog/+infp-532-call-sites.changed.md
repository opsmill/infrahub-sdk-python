Narrow queries made by the SDK itself now use `only`: the group queries of query groups, `infrahubctl generator` and `infrahubctl check`, and the query `RelationshipManager.fetch()` sends for a relationship that wasn't fetched. Group queries request only the identity of their members, so they no longer add every member node to the client store. `infrahubctl object get` leaves out the fields that weren't fetched instead of showing them as empty.
