Narrow queries made by the SDK itself now use `only`: the group queries of query groups, `infrahubctl generator` and `infrahubctl check`, the repository listing of `InfrahubClient.get_list_repositories()`, and the query `RelationshipManager.fetch()` sends for a relationship that wasn't fetched. Group queries request only the identity of their members, so they no longer add every member node to the client store. The repository nodes returned by `get_list_repositories()` carry `name`, `location`, `commit`, `ref` and `internal_status`, and reading any other field of them raises `FieldNotLoadedError`. `infrahubctl object get` leaves out the fields that weren't fetched instead of showing them as empty.
