Added `infrahubctl storage encrypt`, which encrypts the files that an Infrahub server stored before storage encryption was enabled. Before it encrypts, the command lists the files still to process, so the progress line shows the number done out of the total, the percentage, the remaining time at the recent rate and the bytes done out of the total; `--no-count` skips that listing on very large installations. The command pages through the stored files, asks the server to encrypt them in batches, adapts the number of requests in flight to the server and waits when the server answers HTTP 429, and logs in again when a login with a username and password expires during a long run. It saves its position, so that a run stopped with Ctrl-C (exit code 130), SIGTERM (exit code 143) or an error can resume, and it writes a report of the files the server left unchanged.
